# Meta.Ny (http://meta.ny)
### مساحتك الذكية الشاملة للمستندات والترجمة والأسئلة والبحوث والصوت والصور

تطبيق ويب متكامل يجمع 7 خدمات أكاديمية متقدمة في منصة واحدة موجهة للطلاب والأساتذة والباحثين والموظفين في العراق والوطن العربي، بواجهة عربية RTL فائقة الأناقة ومطابقة تماماً للتصميم المعتمد، ومجهزة بنظام اشتراكات VIP ولوحة تحكم حصرية للأدمن وإعلانات Google AdSense ومكافأة ولاء 30 يوماً.

يدعم التطبيق العمل بدون إنترنت كـ **تطبيق تقدمي PWA (Progressive Web App)** مع تخزين محلي مزدوج عبر **IndexedDB** و **localStorage** وشريط تنبيه ذكي عند انقطاع الاتصال وزر تثبيت التطبيق على الشاشة الرئيسية (Install App).

## 🌟 الخدمات السبعة المدمجة

1. **الترجمة متعددة اللغات**:
   - ترجمة سياقية وأكاديمية بين (العربية، الإنجليزية، الكردية، التركية، الفرنسية، الألمانية).
   - وضعان للترجمة: لغة واحدة مباشرة أو الترجمة المزدوجة المتوازية (Dual View).
   - نطق صوتي للترجمة وتصدير فوري.

2. **توليد الأسئلة والأجوبة**:
   - توليد أسئلة اختيار من متعدد (MCQ)، صح وخطأ مع التصحيح، أسئلة مقالية، وأسئلة وزارية ونموذجية.
   - تحديد عدد الأسئلة (5، 10، 20) ومستوى الصعوبة (سهل، متوسط، صعب).

3. **الحل الذكي للأسئلة والتمارين**:
   - حل المعادلات والمسائل والواجبات خطوة بخطوة مثل ChatGPT.
   - أزرار تفاعلية للمتابعة: "اشرح أكثر بالتفصيل والأمثلة" و "حل بطريقة ثانية بديلة".

4. **تحويل الملفات والمستندات**:
   - تحويل فوري بين صيغ Word (`.doc`)، Excel (`.csv`)، PDF، ونصوص (`.txt`).
   - حفظ التنسيق والجداول تلقائياً.

5. **تحويل الصوت (Voice to Text & Text to Speech)**:
   - تفريغ التسجيلات والمحاضرات الصوتية إلى نصوص دقيقة مع علامات الترقيم.
   - قراءة النصوص المكتوبة صوتياً بنقاء عالي.

6. **التعديل على الصور واستخراج النصوص (OCR)**:
   - قص وضبط السطوع والتباين للمستندات والمخططات المصورة.
   - استخراج النصوص بدقة متناهية (OCR) وترجمتها فورياً.

7. **كتابة التقارير والأبحاث بطريقة محترفة**:
   - إنشاء بحث أكاديمي متكامل: الغلاف، جدول المحتويات، المقدمة، مشكلة البحث، الأهداف، المنهجية، الفصول والنتائج، الخاتمة والتوصيات، وقائمة المصادر والمراجع (APA Style).
   - تحديد نوع البحث (مدرسي، جامعي، تخرج، تقرير عمل) وعدد الصفحات (3 إلى 20 صفحة).
   - محرر نصي كامل لتعديل البحث قبل التنزيل بصيغة Word.

## 🚀 دليل النشر السريع (Deployment Guide)

### 1. النشر على منصات مجانية (Free Hosting)

#### أ. النشر كـ Full-Stack على Render أو Railway:
1. ارفع المشروع إلى مستودع GitHub.
2. توجه إلى [Render.com](https://render.com) واختر **New Web Service**.
3. اربط مستودع GitHub وحدد:
   - **Environment**: `Node`
   - **Build Command**: `npm run build`
   - **Start Command**: `npm run start` (أو `tsx server.ts`)
4. أضف متغير البيئة:
   - `GEMINI_API_KEY`: مفتاح Google Gemini API الخاص بك.
5. سيعمل التطبيق مباشرة برابط مباشر مجاني HTTPS.

#### ب. النشر على Vercel (Frontend SPA):
- يدعم المشروع التوليد الثابت `npm run build` في مجلد `dist/`.
- يمكن رفع المجلد إلى Vercel بضغطة زر مع توجيه الـ API إلى رابط Render.

## 🌐 ربط الدومين المخصص `http://meta.ny`

1. في لوحة تحكم مزود الدومين الخاص بك (Cloudflare / Namecheap / GoDaddy):
2. أضف سجل **CNAME**:
   - **Type**: `CNAME`
   - **Name**: `@` أو `www`
   - **Target**: رابط الاستضافة (مثل `meta-ny.onrender.com`).
3. فعّل شهادة SSL المجانية التلقائية وسيعمل موقعك فورياً تحت `http://meta.ny` و `https://meta.ny`.
